brewkit 3.8.1

coffeeschedulingsubscriptions

Tiny helpers for subscription schedules: next delivery dates, skips, pauses and roast calendars — with no dependencies.

npm install brewkit

import { nextDelivery } from 'brewkit'
nextDelivery({ every: '2 weeks', from: lastBag })

Works in Node 14+ and every evergreen browser. TypeScript types included.
